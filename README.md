# פסל: מסה, חלל ואור

**[לאפליקציה החיה: https://sculpt-gh.vercel.app](https://sculpt-gh.vercel.app)**

סדנה לפסל במרחב ציבורי.
שלוש החלטות בונות פסל: **ריבוי** (איי וייוויי, זרעי חמנייה, 2010), **חלל** (הנרי מור, דמות שרועה: פסטיבל, 1951) ו**אור** (ברניני, האקסטזה של תרזה הקדושה, 1652).
הסדנה עונה מיד על שלוש שאלות: מאיפה רואים את הפסל שלם, כמה הוא שוקל, והאם הוא עומד.

## מה יש בה
- **שדה תלת־ממדי אחד שמצייר ומודד:** אותה רשת מרחק (48 בחזקת 3) נבנית ל-marching cubes, ונספרת לנפח, למרכז כובד, לבסיס ולחלל נראה.
- **מרחקי מבט לפי Maertens (1877):** טבעות 45°, 27° ו-18° על הקרקע, מול העומק הפנוי במקום.
- **שמש אשדוד:** מיקום שמש וצל ב-21 ביוני, 21 במרץ ו-21 בדצמבר, לפי שעה.
- **הערכה אוטומטית שמסבירה את עצמה:** לכל בדיקה מה נמדד, איך חושב, תקן, מגבלה וביטחון.
- **מי מוביל:** הכלי, או איש המקצוע שמדרג קודם. ההסכמה נמדדת בקאפה של כהן.
- **אוסף** עם תמונה, **קישור** שפותח את אותו פסל, ו**גיליון A4** לוועדה. הכול בכפתור הלוגו A&I.

## הרצה
```bash
npm ci
npm run dev
```

## בדיקה
```bash
npm run build && node tools/secrets.cjs dist && node tools/speed.cjs dist && npm test
```

## מבנה
- `src/lib/field.ts`: השדה, המדידה, מעטפת קמורה.
- `src/lib/assess.ts`: שמונה הבדיקות.
- `src/lib/maertens.ts`, `src/lib/solar.ts`, `src/lib/kappa.ts`: התקנים.
- `src/data/discoveries.ts`: שלושת הגילויים, עם מקור.
- `src/components/Viewer3D.tsx`: three.js, נטען בעצלות.
- `tests/`: בדיקות יחידה למנוע, ו-Playwright לכל כפתור.
